# 🦷 Dental Connect – Frontend

**Dental Connect** é uma plataforma web desenvolvida para facilitar e centralizar o agendamento de consultas odontológicas.  
Através de uma interface moderna e intuitiva, o usuário pode buscar dentistas e clínicas de diferentes formas: por procedimento, por profissional, por localização no mapa ou agendamento de avaliação.

## Objetivo

Simplificar o acesso a serviços odontológicos por meio de uma plataforma única, com foco em praticidade, usabilidade e organização.

## Funcionalidades Principais

- Listagem de procedimentos odontológicos
- Agendamento por:
  - Avaliação inicial
  - Procedimento
  - Dentista
  - Clínica (com visualização no mapa)
- Interface responsiva e acessível
- Integração com o backend via Supabase

## Tecnologias Utilizadas

- [React](https://reactjs.org/)
- [Supabase](https://supabase.com/)
- [Figma](https://figma.com/) (para prototipagem)
- [Vite](https://vitejs.dev/) (ambiente de build)

## ⚙️ Como rodar o projeto

1. Clone este repositório:
```bash
git clone https://github.com/SEU_USUARIO/dentalconnect-frontend.git
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor local:
```bash
npm run dev
```

A aplicação estará disponível em: http://localhost:5173
